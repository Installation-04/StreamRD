# StreamRD and Phosphor v0.5.0 — Automatic Libraries

Connect your debrid account during onboarding and bring the torrents already in
it into **My library**. Add TMDB or OMDb to enrich titles with artwork, descriptions,
cast, runtime, ratings and IMDb IDs. Imported libraries are private to each user.

## Your account, already filled with things to watch

- Onboarding and saved debrid connections queue a read-only account scan by
  default, with an opt-out. Progress, errors, stopping and deliberate rescans are
  available from Setup and My library.
- Scan Real-Debrid torrents across account pages, AllDebrid magnets, Premiumize
  cloud video folders and, in Phosphor, Torbox torrents. Durable cursors, leases,
  bounded retries and duplicate detection protect longer scans.
- Imports stay out of the shared curated catalog. Search, filter and browse your
  own collection on desktop or mobile. Other users cannot address its items,
  metadata or streams through the personal API.
- Press Play to resolve a fresh stream using your own credentials. Multi-video
  torrents offer file choices; pending items report readiness. The browser player
  supports compatible media and can open a temporary stream in an external player.
- Scans do not create/delete torrents, select provider files, copy videos or store
  signed URLs. Credential changes invalidate stale work and playback bindings;
  rescans preserve manual corrections for an unchanged source.

## Metadata with the final say

**Admin → Metadata** configures TMDB and OMDb with server-only keys. TMDB supplies
movie/TV information and artwork; OMDb supplies IMDb-linked details and ratings.
The UI labels each rating's source and includes provider attribution.

Automatic metadata is opt-in. New catalog entries, mounted exports and personal
imports can queue enrichment. Exact confident matches apply automatically;
ambiguous names and remakes go to review. Existing collections can be scanned in
bounded batches, and confirmed matches can be refreshed on a schedule.

Search by title or IMDb ID, inspect a preview, then confirm a match. Draft catalog
selections retain their provider identity for background enrichment. Field locks,
explicit tracking of provider-written values and revision checks protect manual
edits, including deliberate clears. Members can fix matches on their own imported
items. Private matching records are excluded from the shared admin activity.

Mounted-library enrichment adds web details while preserving original files,
symlinks, export names and scanner layouts. Plex/Jellyfin filesystem export remains
optional and requires real mounted files.

## Upgrade and validation

Two additive migrations extend the v0.4.0 chain with metadata and private account
storage. Existing installations receive the verified pre-change snapshot required
by the upgrade runner. Released migrations and historical checkpoints are unchanged.
Checkpoint generation now reopens SQLite inspection after each external SQL step.

Validation covers **550 backend tests** (304 StreamRD, 246 Phosphor), four production
image builds, disposable upgrade/backup/restore checks, and **20 browser journeys
with 36 screenshots**. Browser checks exercise real app APIs and workers with
test-only provider transport fixtures; a synthetic one-second video verifies the
player path. Live provider credentials were not available, so no real-account scan,
provider quota, copyrighted-artwork download or live-provider playback is claimed.
