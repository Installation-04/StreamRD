# StreamRD v0.12.0 — A Plex-style home page

## What changes
The StreamRD home page now has rows like Plex, top to bottom:

- **Continue watching** — pick up where you stopped, with a progress bar.
- **New in your libraries** — the newest titles in the libraries you can see.
- **Popular on this server** — what people on your server watched most in the last 30 days. Only the ranking is shown, never who watched.
- **Trending now**, **Popular movies**, **Popular TV shows** — public lists with posters and IMDb ratings. Open a title to see its page and request it.

Administrators also see what they imported themselves in *New in your libraries*, even before they put it in a library. The old "From your library" row is replaced by these.

The top navigation is slightly tighter so every item, including Admin, fits on common screens.

## Privacy
The trending and popular lists come from the public Cinemeta catalogues (no account, no key). The server fetches them, keeps them for six hours (and the last good copy for up to a week if the service is down), so browsers never contact the service and nothing about a viewer is sent. Set `HOME_EXTERNAL_LISTS=false` in the container environment to hide those three rows; the library rows keep working.

## Upgrading
`docker compose pull && docker compose up -d`. No database change and no migration; existing data, settings and libraries are untouched. Phosphor is unchanged apart from the version number (its home is a search and queue page).

## Verification
New server tests (stubbed catalogues, never the network) cover the lists, only-allow-listed redirects, poster host filtering, caching, serving the last good copy, the off switch, and that the library rows only contain what the viewer can see and never a viewer's identity. The page was also rendered in Chromium with real catalogue data to check the layout. Not verified: sustained load on the public catalogues, and the look on every screen size (CI browser journeys run the home page).
