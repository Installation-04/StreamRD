# StreamRD v0.41.0 — remove Zilean or Zurg from the Add-ons page

## What changes for the owner
- **A Remove button** on the Zilean and Zurg cards (Admin → Add-ons → Search and library files), next to Start, Stop and Restart. It asks first, then removes the programs: Zilean and its database, or Zurg and the program that mounts your Real-Debrid library.
- **Nothing you set up is lost.** Their settings and data folders stay (including Zurg's `config.yml` and Zilean's database), so pressing **Install** again picks up where it was.
- After Zilean is removed, StreamRD stops using it for request searches within the minute.

## Not done yet
- A removed Zurg may leave its mount folder looking empty until the machine's next restart, or until the folder is unmounted by hand. Plex and Jellyfin started with that folder should be restarted after removing or re-adding Zurg.
- A desktop program that opens videos in mpv or VLC is separate work.

## Nothing is lost or rewritten
No migration, no new setting. New API (administrators): `DELETE /api/admin/addons/services/{zilean|zurg}`. The Docker helper gains `DELETE /services/{zilean|zurg}`.

## Upgrading
`docker compose pull && docker compose up -d`, or the **Update** button.

## Verification
- Helper tests against the Docker stand-in: the program is removed before its database or mount; unknown names are refused; an unauthenticated call is refused; removing something already gone is not an error.
- Server tests: administrators only; only the two services; the helper is asked.
- **Not verified:** removing a real Zurg mount on a real machine (FUSE), and the button in a browser (the Chrome journey runs with both absent, so it shows only Install).
