# StreamRD and Phosphor v0.3.0 — Community Edition

This update makes a fresh installation easier to understand, turns mounted-media
export into a reviewed workflow, and gives both apps a clearer responsive interface.

## A better first session

New accounts arrive at **Setup**, an account-aware checklist with useful next
steps. Administrators see catalog/indexer and optional external-library actions;
members get guidance that respects their permissions. Saved provider configuration
is clearly distinguished from a tested connection. No provider or indexer is
contacted automatically by the checklist.

## A library workflow built for real collections

**Admin → Plex / Jellyfin** now browses your mounted folders and videos. Select
up to 100 files, review editable filename hints for movie years and TV episode
numbers, then export. Successful items persist even if another item fails; failed
items stay in review. Nothing exports merely because a file was selected.

Directory pages have scoped cursors, bounded retained candidates, and confinement
checks. The export list adds search, health filters, link repair, and explicit
removal confirmation. Original media and the existing scanner layouts are preserved.
Normal URL playback still works without the optional mount.

## Interfaces that feel like home

- **StreamRD:** an editorial discovery page, a real collection-based feature panel,
  geometric poster fallbacks, responsive cards/row controls, and improved dark,
  light, and system themes. Favorites and profile progress keep their existing
  behavior. Catalog search has loading/error/empty states and stale-request guards.
- **Phosphor:** a more legible green/amber/white cockpit, responsive navigation,
  richer search results, inline saved-search naming, and recovery-friendly actions.
  The queue adds real-state counts, filters, loading/error/retry states, and clear
  confirmation for removals. Its bounded visible-only refresh loop is preserved.
- Both apps improve control labels, focus visibility, reduced-motion handling,
  small-screen layouts, and access to setup/community guidance.
- Health endpoints report the actual package version instead of an old constant.

## Community delivery and tracking

The repository now includes a project HQ, a task-board CSV, contributor guidance,
issue/PR templates, and a Notion-importable tracker bundle. **A live Notion page
has not been created:** the development session has no Notion workspace connection.
The bundled page/database can be imported now; automatic synchronization is not
claimed. [Project HQ](https://github.com/Installation-04/StreamRD/wiki/Project-HQ)
tracks shipped work, blockers, acceptance criteria, and next priorities.

## Verification

The backend regression suites contain **278 tests** (166 StreamRD, 112 Phosphor).
Checks cover the new browse/batch and private setup APIs alongside existing
playback, account, provider, and recovery behavior. Production builds and disposable
browser checks exercise the actual web/API images; CI retains their screenshots
and reports. See [validation evidence](https://github.com/Installation-04/StreamRD/blob/v0.3.0/docs/community-validation.md)
for the completed results and the distinction between fixtures and real providers.

## Upgrade and limits

No new database schema or filesystem-manifest format is introduced in this update.
Keep the stable JWT secret and existing data/mount paths. Older installations should
still follow the [production upgrade guide](https://github.com/Installation-04/StreamRD/blob/v0.3.0/docs/production-runtime.md).

Filename suggestions need review; automatic provider-to-mount matching and scanner
API synchronization remain manual. A directory is still enumerated per browse
page, so mount latency affects responsiveness. The prior real Plex/Jellyfin scanner
validation remains the compatibility baseline; this update verifies the new workflow
against the same output format rather than claiming a new live-cloud scan.

No live debrid playback, native-device parity, complete WCAG audit, credential
at-rest encryption, or production-load benchmark is claimed. These remain visible
in the engineering roadmap. Release downloads contain source/documentation and
tracker assets, not newly published registry images or native installers.
