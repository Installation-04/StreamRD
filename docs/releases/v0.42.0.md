# StreamRD v0.42.0 — Shuffle on a show page

## What changes for you
- A **Shuffle** button beside Play/Resume on a show's page. It plays an episode picked at random, from any season, and **prefers episodes you have not watched**; once everything is watched it picks from all of them. Press it again for another.
- It only appears for shows with more than one episode.

## Not done yet
Shuffle picks one episode at a time. It does not queue a playlist that carries on to another random episode afterwards (the player's "Up next" still moves to the next episode in order). Extras and related titles, and the file size of each version, are separate work.

## Nothing is lost or rewritten
No migration, no new setting, no server change.

## Upgrading
`docker compose pull && docker compose up -d`, or the **Update** button.

## Verification
- Type-check and production build of the web app pass.
- **Not verified:** the button in a browser. The Chrome journey does not open a show page's episode list, so nothing exercised it.
