# StreamRD and Phosphor v0.11.0 — One Library, Plex-style

## What changes
- **Libraries** (Admin → Libraries, formerly *Shared libraries*): create libraries such as *Movies* and *TV Shows*, and tick **Visible to everyone** to show one to every account on the server, now and in the future. Or choose people one by one, as before.
- **One Library page for everyone.** The navigation now has a single **Library** item. The separate *Shared libraries* and *My library* entries are gone; administrators get **Imports** (their own debrid import screen) next to it.
- Content types read *Movies* and *TV shows*.

## Upgrading
`docker compose pull && docker compose up -d`. One additive database column (`SharedLibrary.everyone`, off for every existing library), applied after the usual automatic backup. Existing libraries, their viewers and watch progress are unchanged. Nothing is deleted.

## Updates stay safe, by test
Every release is now checked so that updating cannot lose data: a test fails if a migration drops, renames or deletes anything (unless a reviewer signs it off with a written reason), and another upgrades a populated database from every earlier version in the migration chain, requiring a backup first and every row unchanged afterwards. The rules are in [RELEASING.md](../../RELEASING.md#updates-must-never-cost-anyone-data).

## Not in this release
Age-rating limits per account (kids accounts), invite links that carry library access, and the dedicated player page are the next steps of [the roadmap](../roadmap.md). Personal debrid accounts for non-administrators still work behind the scenes; their screens are simply no longer linked.

## Verification
New test: an everyone-library is visible to accounts without a grant, pausing hides it, switching back returns to grants only, and creating one with `everyone` works. The migration upgrade tests (including a populated database) pass for both products. Not verified: the full look of the new admin controls in a browser (CI journeys run it).
