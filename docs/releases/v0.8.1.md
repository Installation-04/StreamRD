# StreamRD and Phosphor v0.8.1 — Better matching, logs and a library on the dashboard (release candidate)

Unreleased until both CI pipelines pass on the merged commit and the annotated tag is pushed (see RELEASING.md).

## Automatic metadata matching
Release-style names such as `Crank 2006 Director's Cut 1080p BluRay DTS x264-CtrlHD.mkv`
used to search for "Crank 2006 Director's Cut", never matched exactly, and landed in review,
so every title needed a manual choice. The matcher now cuts the name at the year or the first
quality/audio/codec/edition tag, accepts a single exact title (with or without a year, or off by
one year) and still refuses remakes and ambiguous results. Throughput is higher: several titles
per worker tick and 250 discovered titles every 20 seconds, so a library of thousands is matched in
minutes. Details in [metadata-automation.md](https://github.com/Installation-04/StreamRD/blob/main/docs/metadata-automation.md).

**My library** (both products) shows how many titles are matched, waiting, in review or without a
match, explains why when no provider is configured or automatic matching is off, and has
**Retry matching**, which re-queues your own review, unmatched, failed and never-started titles
(it never touches another user's library). Administrator totals still exclude private libraries.
Names with no readable title (for example a bare hash) cannot be matched and still need a manual choice.

## Your library on the dashboard
StreamRD's Discover page now has **From your library** with your imported titles (artwork first)
and a link to all of them, and no longer shows the empty "Let's build your collection" state when
you have an imported library.

## Admin logs
Search messages; filter by type, level, provider and a date range; page through up to 1000 entries at a
time and **Load more**; **Copy shown** or copy a single entry; open an entry's details; **Live**
refresh; and **Download all matching** as text, JSON lines or CSV (up to 50,000 entries, CSV cells that
start with `=`, `+`, `-` or `@` are neutralized). See the [admin guide](https://github.com/Installation-04/StreamRD/blob/main/docs/admin-guide.md#logs).

No database migration is included.
