# StreamRD v0.40.0 — install StreamRD as an app

## What changes for the owner and everyone you share with
- **Chrome and Edge (Windows, Mac, Android)** now offer to install StreamRD as an app: an **Install app** button appears in the top bar (or use the browser's own install icon in the address bar). It opens in its own window with its own icon, from the Start menu or desktop, like a Plex app.
- It is the same site, so it **streams and controls your server** and is always the same version as the server. Nothing to update on the PC. Sign in once as usual.
- Safari on iPhone and iPad: Share → Add to Home Screen.

## Not done yet
This is the installable web app, not a separate native program. A desktop program that hands videos to mpv or VLC (for formats a browser cannot play) is a separate piece of work.

## Nothing is lost or rewritten
No migration, no new server setting. Adds `/manifest.webmanifest` and three icons; pages and API are unchanged.

## Upgrading
`docker compose pull && docker compose up -d`, or the **Update** button.

## Verification
- Chrome journey: the manifest is served without signing in and its icons load as images; type-checks pass.
- **Not verified:** the install prompt itself (Chrome shows it only on a real browser over https or localhost) and Safari's Add to Home Screen.
