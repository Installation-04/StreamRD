# StreamRD and Phosphor v0.18.0 — The libraries are the product

## What changes
StreamRD no longer has two ways to hold media. The **curated catalogue** (titles with hand-added links and magnets, its own search, title and watch pages, favourites, My List, viewing profiles and *Admin → Catalog*) is **retired**, and **only the administrator imports** from a debrid account. Everyone else watches what the libraries show them and **requests** what is missing.

- The home page is now the carousel and the library rows (Continue watching, New in your libraries, Popular on this server, Trending and Popular). The *Search* menu entry, *Admin → Catalog* and the profile pages are gone; *Library*, *Find media* and *Requests* are how people find things.
- A request is no longer marked "available" because of a catalogue entry; only libraries count.
- The setup checklist drops the catalogue and profile steps and asks for the one thing that matters: finished items in a library.
- Members cannot import from their own debrid account, and no scans are queued for them (both products; Phosphor's search and queue still work for everyone). The personal-import API (`/api/account/library*`) answers **403** to anyone but an administrator. Imports members made before this release stay stored, hidden, and are not shown to anyone.
- The retired endpoints answer **410 Gone** with a plain message instead of disappearing: `/api/catalog/*`, `/api/play/*`, `/api/account/favorites*`, `/api/account/profiles*`, `/api/account/continue-watching`, `/api/admin/catalog*`.
- *Admin → Overview* counts library titles. Configuration exports no longer carry the catalogue; older exports that do still import (the catalogue part is ignored). The demo-data seed script is removed.

## Nothing is deleted
No table, column or row is dropped or changed, so there is no migration in this release, and going back to v0.17.x restores everything exactly: titles, favourites, profiles, watch history and members' earlier imports are all still in the database. A later clean-up, if you want one, will be an explicit, backed-up administrator action with a dry-run report.

## What you lose
Favourites, My List, viewing profiles and hand-added links have no replacement in this release. If you want favourites or "my list" for library items later, it would be built on the libraries, not the old catalogue.

## Upgrading
`docker compose pull && docker compose up -d`. No database change; the usual automatic backup still runs first. Both products; Phosphor has no catalogue, so it only gets the administrator-only import.

## Verification
New tests: every retired endpoint answers 410 and nothing stored is deleted; members get 403 on the personal-import API and no scan is queued for them even with a saved key; the administrator keeps working. The tests that covered the retired features were removed and the importing tests now use an administrator. Browser journeys: the home page, theme switch and mobile layout; the retired pages answer 404; the import, metadata, sharing and request journeys run as before. Not verified: a real install upgraded from a populated v0.17.x catalogue by hand (the every-checkpoint upgrade tests cover the schema, which is unchanged).
