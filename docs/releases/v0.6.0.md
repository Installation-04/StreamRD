# StreamRD and Phosphor v0.6.0 — Server Sharing

Invite people to your server, choose which named libraries they can watch and
supply playback through your own connected debrid account. Viewers no longer need
their own provider keys to watch media you explicitly share.

## People and access

**Admin → Users** now brings registration policy, invitations and member controls
into one responsive page. Choose open, invitation-only or closed registration.
Existing installations keep their current accounts and default to open signup
until an administrator changes it.

Create email-bound invitations lasting 1–30 days, copy the link and send it yourself.
Links work once, can be revoked, and are stored only as hashes. Creating a replacement
invalidates older unused links for the same address. Signup handles opening an
invitation while the signup page is already open, removes its secret from the
address bar and lands invited users in Shared libraries.

Administrators can promote/demote or activate/deactivate other users and sign them
out of all existing sessions. Concurrent changes recheck the acting administrator
inside the transaction and cannot remove every active administrator.

## Your server's libraries

Import your existing provider media into My library, then open **Admin → Shared
libraries**. Create an all-media, movie or series collection, and grant access to
selected users after they join. A collection includes current and future matching
imports from its source administrator. Other users' private accounts are not shared.

Viewers receive a responsive gallery, search, metadata details, file choices and
browser playback. Guided setup recognizes shared content without requiring a
personal debrid account or Phosphor indexer. Source credentials and internal
provider references stay on the server.

Pause a library, remove a grant or deactivate a user to block new requests. Access,
session validity, source credentials and library filters are rechecked around
provider requests and metadata reads. Removing a shared view preserves private
imports, original files and provider content.

## Scope and validation

This provides core server sharing, with local server accounts. It does not connect
to Plex accounts or implement all Plex Home features. PIN-protected managed users,
parental/label restrictions, device inventories, concurrency controls and watch
progress for shared imports remain future work. The legacy curated catalog and
Phosphor search retain their existing access rules; named-library grants apply to
the new shared-library APIs.

Playback returns temporary provider URLs directly to the browser. There is no
proxy or transcoder, and already-issued URLs may remain usable until provider
expiry after access is revoked. Plex/Jellyfin mounted exports keep their own server
permissions and are unchanged.

An additive migration adds invitations, named libraries and grants. Upgrade checks
preserve populated v0.5 users/imports and grant no access automatically. Released
migrations/checkpoints and historical fixtures remain immutable.

Validation covers **642 backend tests** (350 StreamRD, 292 Phosphor), four
production image builds, both upgrade/restore smoke checks, and **26 browser
journeys with 50 screenshots and no page errors**. Both CI pipelines gate the
exact annotated release commit.

See the [users and sharing guide](https://github.com/Installation-04/StreamRD/blob/v0.6.0/docs/server-sharing.md)
and [validation record](https://github.com/Installation-04/StreamRD/blob/v0.6.0/docs/server-sharing-validation.md).
Screenshots, wiki and the Notion-importable tracker are attached with SHA-256
checksums. No live Notion page was created without a workspace connection.

Provider behavior is tested with explicit local protocol fixtures and synthetic
video. No real account credentials were available; live-provider scanning,
quotas and playback are not claimed. No registry images or native installers are
published by this release.
