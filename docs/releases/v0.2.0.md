# StreamRD and Phosphor v0.2.0

StreamRD now browses large catalogs in bounded pages, reuses pending provider work,
offers torrent-file selection, and saves web playback position by profile and file.
Phosphor bounds and shares indexer/download work and backs off queue refreshes.
Both apps can optionally export mounted media as Plex/Jellyfin-compatible symlinks.

## StreamRD

- Compact cursor pages for catalog rows, favorites, and viewing history; indexed
  ordering and bounded visible-card favorite queries. Legacy endpoints remain.
- One resolution attempt budget and upstream deadline across provider/source
  fallback, including response-body reads; settings are captured once.
- Durable user-scoped provider references and leases reuse pending torrent work
  across retries/restarts, with bounded web polling.
- File selection for Real-Debrid, AllDebrid, and Premiumize video packs, with
  opaque scoped choice tokens and sample filtering.
- Profile/file-specific resume, ordered progress updates, stale-player protection,
  and completion handling in the web player and Continue Watching row.

## Phosphor

- Bounded indexer search and download refresh concurrency, configuration-aware
  request coalescing, and invalidation after administrative settings changes.
- Partial indexer results survive failures; transient refresh failures remain
  retryable and delayed results cannot resurrect deleted jobs.
- Web queue refresh uses bounded rotating batches, visibility pausing, backoff,
  and serialized manual actions.

## Both products

- Optional **Admin → Plex / Jellyfin** exports mounted files as movie/episode
  symlinks. Supports years, seasons/specials, idempotent export, persistent private
  manifests, link health/repair, and removal that preserves source files.
- Optional read-only media-mount Compose overrides; URL playback keeps working
  without the mount. Plex/Jellyfin require the same absolute source mount path.
- JWT algorithm/issuer/claim checks, durable logout revocation, password and
  deactivation session invalidation, and serialized first-admin creation.
- Generic unexpected error responses with request IDs and async-route handling.
- Correct production entrypoints, frozen npm installs, non-root Node 22 images,
  pruned compiler/test tooling, explicit web ports, and readiness dependencies.
- Installer reruns preserve `.env` and signing keys. Verified SQLite snapshots
  refuse overwrites; production smoke checks validate restart and backup/restore.
- A wiki, real application screenshots, and checksummed documentation bundles.

## Before upgrading

Back up each database and private configuration. Read the
[production upgrade guide](https://github.com/Installation-04/StreamRD/blob/v0.2.0/docs/production-runtime.md):
old root-owned volumes may require an explicit UID/GID 1000 ownership change.
Supply a stable non-placeholder production signing secret of at least 32 bytes.
Existing users must sign in again because JWT claims changed.

Schema synchronization remains automatic by default without accepting data loss;
set `APPLY_SCHEMA_ON_START=false` for the documented controlled upgrade flow.
Versioned schema migrations are still future work. Back up the optional symlink
library manifest/tree separately from the SQLite database.

## Validation and limits

Local validation includes **256 passing backend tests** (155 StreamRD, 101 Phosphor),
both server type checks, four production image
builds, restart persistence, and successful login/application data after restoration
into fresh volumes. Filesystem regressions cover source/output traversal, symlink
escapes, collisions, concurrent exports, mount outages, manifest persistence,
repair, and removal that preserves originals. Screenshots use disposable demo
data; the gallery explains all fixture data.

Real scanner checks passed on Plex **1.43.5.11079-b3b13e506** and Jellyfin
**10.10.7**: both discovered the symlinked movie and S01E02 episode and served
the original MP4 bytes. External metadata matching and real cloud mounts were
not tested. [Scanner evidence](https://github.com/Installation-04/StreamRD/blob/v0.2.0/docs/media-library-validation.md).

The optional mount is operator-managed (for example rclone/Zurg); this release does
not implement a FUSE/WebDAV bridge, automatic provider-to-mount matching, `.strm`
export, or scanner API synchronization. Library access uses Plex/Jellyfin's own
permissions. See the [Plex/Jellyfin guide](https://github.com/Installation-04/StreamRD/blob/v0.2.0/docs/plex-jellyfin.md).

Native clients do not yet implement the new web file chooser/profile-progress
flow, and no new native binaries or registry images are published. Live debrid
playback and production-load performance remain unverified. Provider keys remain
plaintext in the database and browser tokens remain JavaScript-accessible; the
[optimization plan](https://github.com/Installation-04/StreamRD/blob/v0.2.0/docs/optimization-plan.md)
records remaining work.
