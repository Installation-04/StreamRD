# StreamRD and Phosphor v0.17.0 — One card per title, with versions

## What changes
A debrid account often holds the same film more than once (a 1080p copy and a 4K copy) or a show as several season packs. Until now each copy was its own card. Now a library shows **one card per title**, and the title's page offers the others as **versions**: *This title has 2 versions: 1080p · WEB · H.264 / 4K · BluRay · HEVC · HDR*. Choosing one opens that version; Play uses the version you are on.

- Titles are recognised by their provider id once matched (so *Alien* and *Alien Directors Cut* join), otherwise by cleaned name, year and type. Titles are never joined across different accounts.
- The card shown is the version that is finished, then the newest; if the shown version is removed, another takes its place. Library counts and the home page's *New in your libraries* count and show titles, not copies.
- Versions are labelled from the original release name (resolution, source, codec, HDR) when the server knows it. Titles imported before this release show a plain "Version" label until their next scan fills the name in.

## Nothing is merged or deleted
Grouping only decides what a list shows. Every copy stays a separate item with its own watch position and metadata; the database gains three columns and an index. Existing titles are named automatically when the server starts. See [the library model notes](../library-model.md) for how this fits the larger plan and what is deliberately left.

## Upgrading
`docker compose pull && docker compose up -d`. Additive columns only, applied after the usual automatic backup; no setting changes and nothing is removed. Both products.

## Verification
New tests (both products): title naming and quality labels; one card for several imports with the other versions on its page and every copy still openable; finished beats newer, then newest, and removing the shown copy promotes another; different names of one matched title joining; start-up naming of titles that predate grouping and its idempotence; titles of different accounts never grouped. The migration upgrade tests (every earlier checkpoint) and the additive-migration guard pass. Not verified: a very large library (the grouping runs per page of a scan and once at start).
