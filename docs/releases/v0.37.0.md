# StreamRD v0.37.0 — versions of a movie as a list

## What changes for the viewer
- **A movie that exists in more than one version** (for example 1080p and 4K, or two different releases) now shows them as a **list on its page**, not a small drop-down: for each version its quality (for example "4K · Remux · HEVC · HDR"), the release name it came from, when it was added and whether its link works. The one you are looking at is marked **"Showing this one"**; press another to open it.
- Shows with one download per season keep their **Seasons** list (unchanged).

## Not done yet
File size and audio languages per version (the server does not store a file's size for a title; it is only known once the file is opened), and choosing a default version per person.

## Nothing is lost or rewritten
Web page only. No migration, no new API, no stored data.

## Upgrading
`docker compose pull && docker compose up -d`, or the **Update** button.

## Verification
- Type checks for the four apps. The Chrome journey step that switches between the two versions of "Big Buck Bunny" now presses the other version in the list instead of using the drop-down.

**Not verified:** Safari and Firefox, and a title with many versions (the list shows up to 20).
