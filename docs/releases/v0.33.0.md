# StreamRD v0.33.0 — Resume and Start over on a movie's page

## What changes for the viewer
- **A movie you stopped in the middle of now says so on its page**: the main button reads **▶ Resume 25:00** (where you stopped) instead of "Play from server".
- **Start over** next to it plays the movie from the beginning. Nothing is lost: pressing Resume still returns to where you were until you play on from the start.
- A movie you have not started, or one you finished, shows the usual **Play** button.
- Only you see your own position; others on the server keep theirs.

## Not done yet
Audio and subtitle choice before playing, a version picker that shows each file's size and quality side by side, extras and "related" titles. Shows keep their own Resume / Play next button (v0.31.0).

## Nothing is lost or rewritten
No migration. The title's page answer gains `item.resume` (`positionSeconds`, `durationSeconds`, `percent`, or null). The player accepts `?restart=1` for the first play only.

## Upgrading
`docker compose pull && docker compose up -d`, or the **Update** button.

## Verification
- Server test: nothing to resume at first; after a begun file the position and percent come back; another viewer gets none; a finished file clears it.
- Type checks for the four apps and the shared-files check.

**Not verified:** the buttons and Start over in a real browser (no new Chrome step), and Safari and Firefox.
