# StreamRD and Phosphor v0.24.1 — Requests approve themselves, Prowlarr comes with the server, and posters have a menu

## Requests no longer wait for an administrator
A request is approved by the server when it arrives: it finds the best release (1080p, H.264 and AAC first, a season pack for a show) and sends it to the first administrator who has a working cloud download account and an enabled library for that kind of title. A link that stops working asks for its replacement the same way. The request's history says what happened. Where the server cannot (no indexer yet, no release found, no cloud account, no library), the request waits for a person with the reason in its history, and the server tries again every fifteen minutes for two weeks.

**Admin → Server → Approve requests automatically** turns this off (`REQUESTS_AUTO_APPROVE=false` sets the starting value); then every request waits for an administrator, as before. An administrator's own approval is the same code and reads as before.

## Prowlarr is installed and started by default
Where Docker control is on (the installer's default), the server starts [Prowlarr](https://prowlarr.com) once after it starts, in a container of its own next to StreamRD, unless it was removed. StreamRD reads Prowlarr's API key from the settings folder they share, and every enabled torrent indexer in Prowlarr becomes a source for the release search, found automatically and kept in step every ten minutes. **Admin → Request settings → Release search** shows Prowlarr's state with *Open Prowlarr*, *Sync now*, *Start* and *Remove*; a removal is remembered.

A new Prowlarr has no indexers, and none are added for you: open it and choose the sources you want. Prowlarr is GPL-3.0 software that is run as a separate container (the image from LinuxServer.io); it is not bundled with, or linked into, StreamRD. It is given only a folder for its own settings (`config/prowlarr`), nothing of your libraries or downloads.

## Posters
- **A check on what has been watched**, in the corner of the poster.
- **The three dots at the foot of every poster** (My List too): *Mark as watched / unwatched*, *Add to / Remove from My List*, *Fix match…* (administrators; the same picker as on the title's page) and *Get info* (title, file name, quality, provider, link and match state, age rating, when it was added).
- **What you are watching is on the dashboard only.** The library page no longer lists "Continue watching" above the libraries.

## A bug fixed (reported on v0.23.2)
A title that is in a library more than once, or in a shared library as well as the account's own, showed several buttons that all read "Open in my library" or "Open in shared library". Each button now names its library and the copy it opens, and an item the account already opens as its own is no longer offered a second time through a library it shares.

## Nothing is lost or rewritten
No migration. New stored values: the choice made in Admin → Server for automatic approval, and Prowlarr's state and indexer list.

## Upgrading
`docker compose pull && docker compose up -d`, or the **Update** button. An install with Docker control starts Prowlarr about twenty seconds after the server starts; the first start downloads its image. An install without Docker control (see Admin → System) keeps working as before and says so on the Release search page.

## Verification
- Server tests, StreamRD and Phosphor: new ones cover automatic approval (the best release, the target account and library, each reason it waits, the setting, the retry, an inactive administrator's library), the helper's Prowlarr specification (only its own folder), Prowlarr's start, removal and indexer sync against a stand-in, and the distinct availability buttons.
- The owner's journey in Google Chrome now also drives the poster menu (check, info window, Fix match for the administrator only) and asserts that the library page lists nothing being watched.
- The check against a real Docker daemon now also starts the real Prowlarr image by default, checks it is given only its own folder, wired and reachable from StreamRD, and removes and starts it again.

Not verified:
- **A Prowlarr with indexers.** The real image is started and reached, but no real indexer was added or searched; indexer sync and the release search were run against stand-ins.
- **Automatic approval against a live debrid account and live indexers.**
- Phosphor's pages in a browser; browsers other than Chrome.
