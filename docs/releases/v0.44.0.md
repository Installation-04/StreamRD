# StreamRD v0.44.0 — GPL-3.0 licence

## What changes
**StreamRD and Phosphor are now licensed under the GNU General Public License v3.0**, the same licence as DUMB, instead of MIT. The `LICENSE` file is the standard, unmodified GPLv3 text.

- You can still use, change and share it. If you distribute something built from StreamRD or Phosphor, it has to stay under GPL-3.0 with its source available.
- **Running it for yourself and your household does not change anything.** The licence limits what you may do when you pass the code on to others.
- **Versions up to and including v0.43.0 were released under MIT.** Anyone who received those keeps that licence for those versions.
- The programs StreamRD installs for you (Zurg, Zilean, Jellyfin, Plex, Sonarr and the rest) are separate programs by other people, each under its own licence. Nothing about them changes.

## What was checked
- The only authors in the history are the repository owner's account and one other commit author whose email matches the owner's, so no third party's work was relicensed.
- The installed dependencies (MIT, Apache-2.0, BSD, ISC, MPL-2.0, LGPL-3.0) are compatible with GPL-3.0. This was checked by reading each package's declared licence, not with a dedicated licence scanner.
- Package metadata now says `GPL-3.0-only`.

## Not done yet
Per-file licence headers in the source files (the repository-level licence applies to all of it). The images and release files do not yet carry a separate third-party notices file.

## Nothing is lost or rewritten
No code, setting or API change. Versions in the five package files move to 0.44.0.

## Upgrading
`docker compose pull && docker compose up -d`, or the **Update** button.

## Verification
Documentation and metadata only. `LICENSE` is byte-for-byte the same file DUMB ships; the usual checks (type-checks, server tests, container build, Chrome journey) run on the pull request.
