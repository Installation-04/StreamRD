# StreamRD and Phosphor v0.14.0 — Viewing limits: a kids account

## What changes
An administrator can now give any member a **viewing limit** in **Admin → Users → Viewing limit**:

| Level | Sees |
|---|---|
| **Kids** | G, TV-Y, TV-G, TV-Y7 |
| **Pre-teens** | up to PG and TV-PG |
| **Teens** | up to PG-13 and TV-14 |
| **Mature** | up to R and TV-MA |
| No limit (default) | everything, including unrated titles |

A limited account sees only titles in the libraries it has access to that are **rated at or below its level**. A title with **no rating is never shown** to a limited account: an unknown title is not assumed to be suitable. Hidden titles do not exist for that account (no listing, no search result, no detail page, no playback, not on the home page). The limit is read on every request, so changing it applies immediately without signing in again. Administrators are never limited.

- **Where ratings come from:** the rating in the title's metadata (TMDB and OMDb provide it automatically), or one the administrator sets by hand on the title's page (**Age rating**, administrators only). A hand-set rating wins over metadata and can be cleared. The built-in no-account metadata source has no ratings, so with it you rate titles by hand (or add a free TMDB key and let matching do it).
- **Kept simple for limited accounts:** Find media, Requests, Imports, Setup and search are closed to them (and hidden from the navigation), and the home page shows only their libraries, with no public trending lists. They keep Library and Account.
- Accepted labels: G, PG, PG-13, R, NC-17, TV-Y, TV-Y7, TV-G, TV-PG, TV-14, TV-MA, and plain ages such as 12 or 16.

## Upgrading
`docker compose pull && docker compose up -d`. Four additive database columns (a viewing limit on users; rating fields on imported titles), applied after the usual automatic backup. Everyone starts with **no limit**, so nothing changes until you set one. When the server starts it fills in ratings from metadata that is already stored. Nothing is deleted.

## Verification
New tests (both products) cover the label-to-age mapping, who may set a limit, which titles a limited account can list, search, open and play at each level, that unrated titles stay hidden, hand-set ratings (set, override metadata, clear), that limits apply immediately, and that discovery, requests and personal libraries are closed to limited accounts only. The migration upgrade tests, including every earlier checkpoint, pass. Not verified: how this behaves with a very large library, and ratings in non-US schemes beyond plain ages.
