# StreamRD and Phosphor v0.20.0 — My List

## What changes
Favourites left with the catalogue in v0.18.0. They are back, built on the libraries.

- **A heart on every title.** On a library's grid and on a title's page, the heart (or **Add to My List**) saves the title to **your own list**. Nobody else sees or changes it.
- **My List** is in the menu and, in StreamRD, a row on the home page right after Continue watching. The My List page shows everything you saved, newest first, with the same hearts to take things off.
- **Versions share one heart.** A title that exists as a 1080p and a 4K copy is one entry; the list always shows the version the library shows (and follows it if a broken link makes another version the shown one).
- **It respects who can see what.** You can only save titles you can see, and the list only shows titles in libraries you can see now and within your viewing limit. If a library is taken away, its titles leave your list view but stay saved, and come back with access. A kids account keeps a list of what it is allowed to see.
- Up to 500 titles per person. The list goes with the account if the account is removed.

## Nothing is lost or rewritten
One new table (`LibraryFavorite`, migration `20261115000000_library_favorites`, additive, applied after the usual automatic backup); it starts empty. The retired catalogue's old favourites stay where they were, unused. Both products.

## Upgrading
`docker compose pull && docker compose up -d`. Going back to v0.19.x ignores the new table.

## Verification
New tests (both products): add, list, flags on a library's items, a title's page and the home rows, and remove; newest-first order and per-person lists; versions as one entry with the shown version listed; a title not shared with someone cannot be saved by them, a revoked library hides entries without deleting them, and they return with access; a title above a viewing limit cannot be saved and is not listed; the 500-title cap; the list removed with the account; and the StreamRD home row. The migration upgrade tests (every earlier checkpoint) and the additive-migration guard pass. The browser journey hearts a title as an invited viewer, finds it on My List, and checks that the administrator's list stays empty. Not verified: a very long list on a slow connection (the list is capped and loaded in one request).
