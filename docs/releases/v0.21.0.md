# StreamRD v0.21.0 — Watched marks

You can now see what you have already watched, and filter it away.

- **A Watched badge.** Titles you have finished show **✓ Watched** on library cards and on My List. A title counts as watched when you watch it to the end (95% or more) in the player, or when you mark it yourself.
- **Mark as watched / unwatched.** A button on every title page. Marking a title watched also clears its half-finished resume point, so it leaves *Continue watching*; marking it unwatched starts it again from the beginning.
- **An Unwatched view.** The library page has a **Show: All titles / Unwatched** filter, so a movie night starts with things nobody has seen.
- **Versions count as one.** A title that exists as a 1080p and a 4K copy is watched when either one is.
- **Your own, and private.** Watched state belongs to each viewer. Nobody else sees it, and it follows the same access rules as everything else: you can only mark titles you can see.

## Nothing is lost or rewritten
No migration: the player already recorded when a title was finished. Marks you set yourself use the same table. Going back to v0.20.x ignores them.

## Scope
StreamRD only. Phosphor has no player, so it shows no watched marks.

## Upgrading
`docker compose pull && docker compose up -d`.

## Verification
New tests: marking and unmarking for one viewer and not another; finished playback counted as watched; the Unwatched filter and its total; a resume point cleared and restored; any version counting for the title; and refusal for someone who cannot see the title or is signed out. Not verified: a very large watch history on a slow connection (the filter reads up to 5000 finished items).
