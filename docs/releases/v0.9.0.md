# StreamRD and Phosphor v0.9.0 — A config/data container, movies and shows only, Zilean and Zurg

## One container, two folders, update by pulling
The all-in-one image now keeps settings and data apart: `config/` (databases, backups, secrets, the download
client's settings) and `data/` (downloads and media). **Updating is `docker compose pull && docker compose up -d`**; both folders are untouched and
each database is snapshotted before any migration. `get.sh` generates the compose file, creates the folders with the right ownership, updates
in place when re-run, and can move an existing install across with `--import-db` and `--jwt-secret` (old logins stay valid). Existing
single-volume installs are unaffected unless you set `CONFIG_DIR`. Admin → System shows the update command with a Copy button.
See the [single-container guide](https://github.com/Installation-04/StreamRD/blob/main/docs/single-container.md).

## Movies and shows only
Account scans skip games, software, music, books and names with no readable title (a bare hash), and **My library** can list and remove what
was imported earlier, after a preview and a confirmation. Nothing is removed from the debrid account. Real releases are recognized by their
resolution, codec and source tags, so *The Hunger Games* and *Game of Thrones* stay.

## Optional Zilean and Zurg
`get.sh --zilean` runs Zilean (Debrid Media Manager's torrent index) and Phosphor registers it as a Torznab indexer automatically.
`get.sh --zurg --rd-token …` mounts your Real-Debrid movies and shows (free Zurg build, Real-Debrid only, Linux hosts) for StreamRD's
Plex/Jellyfin exports, with a config that includes only video torrents. Details and limits: [zilean-zurg.md](https://github.com/Installation-04/StreamRD/blob/main/docs/zilean-zurg.md).
