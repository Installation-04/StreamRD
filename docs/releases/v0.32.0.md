# StreamRD v0.32.0 — mark episodes and seasons watched

## What changes for the viewer
- **A ✓ button on every episode** of a show's page marks it watched, or unwatched when it already is. It is yours only: other people on the server keep their own marks.
- **"Mark season N watched / unwatched"** above the episode list does a whole season at once.
- The **Resume / Play next** button follows the marks, so marking the first episodes watched moves "Play next" on to the first one you have not seen.
- Unmarking an episode also clears its resume position.

## Not done yet
Audio and subtitle choice before playing, shuffle, and the movie page options (versions picker, extras). A show kept as one download per season still marks one season download at a time.

## Nothing is lost or rewritten
No migration. A mark is stored as a finished play of that file in the existing watch-progress table. New API: `POST /api/shared-libraries/:id/items/:itemId/episodes/watched` with `{ tokens, watched }` (the choices the episode list gave, up to 400). The server turns them into file keys itself; no keys or links reach the browser.

## Upgrading
`docker compose pull && docker compose up -d`, or the **Update** button.

## Verification
- Server test: marking and unmarking by file choice; another viewer's marks are untouched; no file keys in the answer; unknown choices are refused (409) and an empty list is refused (400).
- Type checks for the four apps.

**Not verified:** the buttons in a real browser (no new Chrome step yet) and Safari and Firefox.
