# StreamRD v0.36.0 — the player remembers your audio and subtitle language

## What changes for the viewer
- **Choose a language once and the next videos follow it.** If you pick French in the Audio menu, the next video that has a French audio track opens with it. If you pick a subtitle language, the next video with that language opens with those subtitles on. Choosing **Off** for subtitles is remembered too.
- A video that does not have your language plays as usual (first audio track, subtitles off unless you chose otherwise).
- The choice is kept **in this browser** (not on the server), so it is per device and is forgotten when you clear the browser's site data.

## Not done yet
Keeping the choice across devices (it would need to be stored with your account), picture subtitles, and subtitle styling.

## Nothing is lost or rewritten
No migration and no server change: the browser stores `streamrd.player.language` (the language codes only, for example `{"audio":"fre","subtitles":"off"}`).

## Upgrading
`docker compose pull && docker compose up -d`, or the **Update** button.

## Verification
- Type checks for the four apps and the shared-files check. The player has no automated browser test for this.

**Not verified:** the behaviour in a real browser (the lab media has one audio track and no subtitles), Safari and Firefox, and private windows where the browser refuses to store the choice (then it simply does not carry over).
